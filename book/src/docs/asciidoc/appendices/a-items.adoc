== Items

Every item of the roadmap, with its status and where it is described.
An item has an id that does not change when its title does, so that another plan can refer to it.

[.sketch]#SKETCH# means there is code in this repository, built and tested with every build.
[.planned]#PLANNED# means designed or intended, and not built.

The models in `models/runtime`, `models/tower` and `models/technology` are marked [.planned]#PLANNED# although each has an Xcore file there.
The files are the pre-SDK models, kept to be read.
An item becomes a [.sketch]#SKETCH# when it is rewritten on the SDK and builds here.
